# 작업 안내 — Claude · GPT(Codex) 공동 작업

이 폴더는 HOI4 기본 중점 확장 모드(1035칸)의 **설계 자료**다. 사람 한 명이 Claude 와 GPT 에게 갈래를 나눠 맡긴다.
두 AI 는 서로 대화하지 않고 **이 저장소의 파일로만** 협업한다.

- 저장소: `skleton12/hoi4_-`
- 브랜치: `claude/brave-bardeen-n1yqiz`
- 폴더: `design/generic_tree/`

## 먼저 읽을 것

1. `SPEC.md` — 데이터 형식과 모티브
2. 맡은 `data/*.json` 파일

## 할 일

맡은 파일의 각 소갈래 `focuses` 배열을 **정확히 `target` 개**의 포커스로 채운다.

```json
{ "name": "산업 조사", "effect": "민간공장 +1", "days": 35 }
```

## 하지 말 것

- 맡지 않은 파일을 고치지 않는다. 다른 AI 가 같은 시간에 작업 중일 수 있다.
- `id`, `title`, `after`, `exclusive`, `condition`, `target` 을 바꾸지 않는다. 틀은 사람이 정한다.
  바꿔야 한다고 생각되면 고치지 말고 커밋 메시지나 답변에 제안으로 남긴다.
- 다른 파일에 이미 있는 포커스 이름을 다시 쓰지 않는다 (`check.py` 가 잡는다).

## 끝내기 전에

```bash
python3 design/generic_tree/check.py    # 오류 0 이어야 한다
python3 design/generic_tree/render.py   # img/ 그림 갱신 (Pillow 필요)
```

`check.py` 가 오류를 내면 커밋하지 않는다. 커밋 메시지에 어느 갈래를 채웠는지 적는다.
충돌을 피하려고 **맡은 data 파일과 그 그림 파일만** 커밋한다. `img/00_overview.png` 는 마지막에 정리하는 쪽이 갱신한다.

## 분담표

사람이 정한다. 아래 담당 외의 파일은 맡기 전에 묻는다.

2차 정리에서 Claude 가 사람의 요청으로 전체를 넓고 얕은 틀로 바꾸고 비슷한 칸을 합쳤다(720 → 331). 이후 정치를 154칸으로 늘리고 이념마다 합법 집권 ↔ 내전 경로를 넣었다. 이어서 이념별 간부 내각과 정권 위기 경로를 더했고, 비동맹 모델을 8개로·민주와 파시즘 모델을 4개로 늘렸다(합계 431). GPT가 제도·통치 중점 60칸을 추가하여 정치 271칸, 전체 491칸으로 확장했다. Claude 검토에서 겹치는 칸을 합쳐 정치 228칸, 전체 448칸이 됐다(POLITICS_COLLAB.md). 이어서 사용자 요청으로 참고 모드와 비교해 얇은 갈래(산업·군사·괴뢰국·후반부·지역)를 200칸 늘렸다(합계 648). 이어서 판무관부·협력정부 전용 소갈래 16칸을 더했다(합계 664). 사용자 요청으로 지역별 길(남미·발칸·중동·아시아) 40칸을 빼고, 지형 특화를 산업 안 조건부 소갈래로 옮기며 효과를 실제 효과로 강화했다(합계 624). 이어서 도시화·농촌화를 10칸씩으로 늘리고, 외교를 다시 짜 진영 가입·보장·자체 진영·정보 기관을 실제 효과로 만들었다(합계 647). 0.3.0 에서 굳이 나뉜 칸을 합쳤다: 이념 모델 머리 칸과 제도 칸을 한 칸으로, 나란한 3칸 소갈래 둘을 5칸 사슬 하나로(합계 597). 0.3.1 에서 도시화·농촌화를 함께 할 수 있는 도시·농촌 개혁으로 바꾸고, 정치 모델 21개에 5칸씩(+105), 종주국 갈래 14칸을 더했다. 공통 시작·후반부 갈래는 산업·군사·외교로 옮겼다(합계 716). 이어서 종주국 갈래에 10칸을 더했다(합계 726). 0.4.0 에서 정치 모델 21개를 11칸에서 30칸으로 늘리고(본 사슬·마무리에 확장 4칸씩, 상호배타 노선 4칸 둘, 결말 3칸) 일직선을 가지 구조로 바꿨다(합계 1125). 0.4.1 에서 비동맹 모델 8개를 5개로 합쳤다(군부 통치·개발 독재·왕정과 전통·농민 민중주의·종교 지도자 통치, 합계 1035).
GPT 담당 갈래는 GPT 가 지은 이름을 최대한 살려 합치고 효과를 다시 붙였다. 그림은 모두 render.py 하나로 그린다.
