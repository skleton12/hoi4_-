# 정치 중점 공동 작업 기록

사용자 요청: Claude와 GPT가 협업하여 정치 중점을 더 늘린다.

## 이번 GPT 변경

- 기준: Claude의 `df8dbc1` (정치 154칸, 전체 374칸).
- Claude가 만든 154칸과 모든 기존 그룹의 선행·상호배타·조건·목표 수를 그대로 보존했다.
- GPT가 `gpt_`로 시작하는 20개 그룹, 60칸을 추가했다. 정치 214칸, 전체 434칸.
- 네 이념의 집권 후 행정 그룹 12칸, 15개 세부 모델의 제도 그룹 45칸, 망명정부의 귀환 준비 3칸이다.
- 기존 경제·외교·군사 갈래와 나란히 이어지므로 기존 이념 모델 경로의 깊이를 늘리지 않는다.
- 기존 합법 집권 ↔ 무장 봉기 → 정부의 합류를 유지한다.
- `check.py`: 434/434칸, 오류 0. `render.py`로 그림을 갱신한다.

## 파일에서 협업하는 방법

- Claude: 기존 그룹과 이념 집권/세부 모델의 핵심 구성 검토.
- GPT: `gpt_` 그룹의 제도·통치 구성과 이번 추가분 유지.
- 같은 JSON을 수정하므로 작업 전 최신 브랜치를 가져오고, 상대가 작성한 그룹을 보존한다.
- 이번 커밋은 Claude의 응답이나 검토 완료를 뜻하지 않는다. 아래 사항은 후속 검토 요청이다.

## Claude에게 남기는 검토 요청

1. 추가 60칸이 기존 154칸과 기능상 겹치는지, 모델별 제도 구성이 적절한지 검토한다.
2. 기존 `neu_legal`의 「권위주의 헌법」에 비동맹 정부 전환을 명시할지 검토한다.
3. 정치의 진영 접근과 외교의 무장 중립이 충돌하지 않도록 후속 조건을 설계한다.
4. 외교의 지역 진영 창설 후 지역별 갈래에서 다시 진영을 만드는 부분은 확대/개칭으로 정리할지 검토한다.
5. 정치 그림의 가로 폭이 커졌으므로 이념별 확대 그림도 제공할지 검토한다.

위 기존 항목은 이번 GPT 커밋에서 변경하지 않았다.
