# 효과 작동 현황 (0.4.2)

포커스 효과 문구는 `build_mod.py` 의 `rewards()` 가 아는 형식만 실제 게임 효과로 바뀐다.
모르는 문구는 툴팁(`설계 효과: ...`)에만 보이고 **게임에서는 아무 일도 일어나지 않는다.**
그래서 한 칸 안에서도 "어떤 건 되고 어떤 건 안 되는" 일이 생긴다.

- 전체 1035칸 중 실제 효과가 하나라도 있는 칸: 약 913칸
- 실제 효과가 없는 문구 조각: 157개 (0.4.2 에서 음수 15개를 고친 뒤)

## 0.4.2 에서 고친 것

- **음수 값이 무시되던 문제.** `안정도 -3%`, `전쟁 지원 -10%`, `육군 경험 -20` 처럼 대가로 붙은 값이
  적용되지 않아 보너스만 받았다. 이제 음수도 적용된다(15곳).

## 아직 문구만 있는 것 (종류별)

| 종류 | 예 | 필요한 것 |
|---|---|---|
| 장성·원수·고문 영입 | 육군 장성 1명 영입 | 캐릭터 정의 또는 무작위 장성 생성 효과 |
| 사단 생성 | 민병 사단 2개 생성 | 사단 템플릿·`load_oob` 또는 `create_unit` |
| 디시전·공작 해금 | 평화 협상 디시전 해금 | 디시전 정의 |
| 우호도 | 소련 우호 +25 | `opinion_modifiers` 정의 |
| 전쟁 목표·영유권 | 이웃국 영유권 주장 | 대상 주 선택 스크립트 |
| 내전·정권 | 공산주의 내전 발발, 국왕으로 교체 | 내전 설계(플레이어가 어느 쪽인지) |
| 교리 비용 | 육군 교리 비용 -10% | 1.19.3 수정자 이름 확인 |
| 분야 연구 | 해군·잠수함·주력함·항모·기뢰·차량·항공기 연구 | 1.19.3 기술 범주 이름 확인 |
| 세부 수정자 | 방첩, 사단 증원·이동 속도, 함선 수리, 호송·대잠 효율, 방공, 폭격 효율 | 1.19.3 수정자 이름 확인 |
| 건물 | 공군 기지·비행장·레이더·합성 정유소·국경 요새 | 건물 이름 확인 후 `add_building_construction` |
| 법 | 경제법·징병법 한 단계 상향 | 현재 법에 따른 분기 스크립트 |

## GPT 확인 요청 (게임 설치 폴더)

1. `common/technology_tags/*.txt` — 해군·잠수함·주력함·항모·기뢰·차량·항공기 기술 범주 이름
2. 수정자 이름 — 교리 비용(육·해·공), 방첩, 사단 증원·이동 속도, 함선 수리, 호송·대잠 효율, 방공 효율
   (`documentation/` 또는 콘솔 `script_docs` 로 뽑은 modifiers 목록)
3. 건물 이름 — 공군 기지·레이더·합성 정유소·육상 요새 (`common/buildings/00_buildings.txt`)
4. 결과를 이 표에 적어 주면 Claude 가 `build_mod.py` 에 연결한다.
