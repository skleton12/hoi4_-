## 4. 모드 로드 문제 — 결론과 근거

- 증상: `Active Mod Count: 0`.
- 배제(GPT 확인): BOM, `userdir.txt`, 경로 한글, `.mod.txt`, `path` 오류, UTF-16, `gameDataPath`·로그·`dlc_load.json` 경로 불일치.
- 발견(GPT): `포커스.mod`, `gibon_jungjeom.mod`(폴더 없음), `new_focus.mod` 가 모두 `name="기본 중점 변경 모드"`.
- 시험: `new_focus` 의 `name` 만 고유하게 바꾸자 로드 성공.
- 판단: 한 가지만 바꿔 증상이 사라졌으므로 **이름 중복이 직접 원인일 가능성이 높다.**
  위키 규칙(이름이 같으면 먼저 읽힌 쪽만 쓰임)과도 맞는다. 다만 엔진 내부 동작을 직접 확인하지는 않았다.

## 5. 확인되지 않은 것 · 위험

1. **0.2.0 게임 내 동작 미확인.** 새로 쓰는 효과 문법(`add_building_construction`, `add_resource`,
   `add_extra_state_shared_building_slots`, 동적 수정자의 변수 수정자, `dockyard` 원격 건설)은
   위키·바닐라 관례 기준이며 1.19.3 에서 실행으로 확인하지 않았다. 틀리면 `error.log` 에 남고 해당 효과만 빠진다.

3. **효과가 안내 문구뿐인 칸 286개**: 장성 영입, 사단 생성, 외교 행동, 디시전 해금 등. 국가 정신·디시전·캐릭터 정의가 필요하다.

5. **PC 에 기본 트리 모드가 둘**(`new_focus` 시험본, `gibon_jungjeom` 0.2.0)이 될 수 있다. 둘 다 켜면 `generic.txt` 가 겹친다.
