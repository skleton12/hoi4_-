# HOI4 기본 중점 변경 모드 공동 작업 보고서

작성일: 2026년 10월 12일 (한국 시간)

GPT가 PC 검사 결과와 저장소의 Claude 커밋을 바탕으로 작성한 통합 보고서다. Claude가 이 문서를 직접 작성하거나 최종 검토한 것은 아니다.

## 결과

HOI4 1.19.3.0.c01a (5632)에서 모드 로딩 성공과 사용자 적용 확인을 확보했다. 현재 시험판은 448개 중점을 포함한다. 한국어 번역을 설치했고, 기본 게임 아이콘 6종을 모드 안에 복사하여 모든 중점에 연결했다. 아이콘 수정의 실제 게임 화면 결과는 아직 확인하지 않았다.

## Claude 작업 기록

- 정치·외교 등 구성과 전체 트리의 병합·확장을 수행했다. 중간 설계는 491칸이었지만 후속 정리 후 현재 게임용 시험판은 448칸이다.
- `build_mod.py`로 설계 자료를 `generic.txt`와 이름·설명·효과 안내로 변환했다 (`356c0a0`).
- BOM 방지, 사용자 폴더 비교, 중복 모드 이름 경고를 설치·진단 도구에 반영했다.
- 이름 중복과 사용자 폴더 등 로딩 원인 후보를 `MOD_LOADING.md`와 `POSTMORTEM.md`에 정리했다.

## GPT 작업 기록

- 산업·군사·지형·독립·후반부 설계, 정치 제도·통치 60칸 추가, Claude 동시 변경 통합을 수행했다.
- 사용자 PC의 설정, 런처 DB, 게임 파일, 실행 명령줄, 원본 바이트, 로그를 대조했다.
- 없는 D:/E: 드라이브에서 설치가 멈추는 문제를 수정했다 (`43931e7`).
- 모드 대상 버전을 `1.19.3.*`로 맞췄다 (`4492523`).
- `new_focus`의 두 설명 파일에서 표시 이름만 고유하게 변경하여 이름 중복을 시험했다.
- 한국어 게임 설정에 대응하는 `l_korean` 파일을 추가했다 (`8582cb5`). 언어별 정상 번역 키를 중복으로 잘못 판단하던 검사기도 수정했다 (`0982897`).
- 게임에 설치된 기본 아이콘을 6종 복사하고 일반·완료 효과 스프라이트 12개를 `GFX_GJ_` 이름으로 정의했다. 448개 중점의 참조를 바꾸고 PC의 `new_focus`에도 설치했다.

## 로딩 실패 원인과 근거

이름 변경 전에는 `포커스.mod`, `gibon_jungjeom.mod`, `new_focus.mod`가 모두 같은 표시 이름을 사용했다. 이 중 `gibon_jungjeom.mod`는 존재하지 않는 폴더를 가리켰다.

`new_focus`의 표시 이름을 `기본 중점 변경 모드 - new_focus 독립시험`으로 바꾼 후 22:55:43 로그가 다음과 같이 바뀌었다.

```text
Active Mod Count: 1
Active Mod: 기본 중점 변경 모드 - new_focus 독립시험
```

체크섬은 `5632`에서 `ac2a`로 바뀌었고, 사용자가 적용 성공을 확인했다. 이름 중복이 로딩 실패 원인이었다는 강한 근거다. 중복 후보 중 어느 설명 파일이 엔진에서 먼저 선택됐는지는 파일 접근 추적으로 입증하지 않았다.

현재 설치본의 BOM, 숨은 `.txt` 확장자, UTF-16, 한글 사용자 경로, `path` 오타, 사용자 폴더 불일치는 확인되지 않았다. 이는 당시 확인된 설치 상태에 대한 결과이며 모든 환경에 대한 일반 결론은 아니다.

## 이름과 아이콘 수정

게임 언어는 `l_korean`이었지만 모드는 `l_english` 파일만 제공했다. 한국어 파일에 1,344개 이름·설명·효과 키와 UTF-8 BOM을 추가해 설치했다. 실제 표시 결과는 재실행 후 확인해야 한다.

아이콘 6종: 정치, 산업, 군사, 외교, 기반시설, 생산. 원래 참조했던 기본 아이콘도 게임에 존재했으므로 처음에 아이콘이 보이지 않은 직접 원인은 아직 입증하지 못했다. 요청에 따라 모드에 이미지와 스프라이트를 직접 포함하여 연결을 명확히 했다. 448개 중점이 모드 전용 스프라이트를 참조하고 각각 완료 효과 정의도 가진다.

## 검증과 한계

- 사용자 확인: 모드 적용 성공.
- 정적 모드 검사: 오류 0, 경고 0 (기본 모드).
- 검사기 회귀 테스트: 26/26 통과 (한국어 처리 수정 시점).
- 아이콘 검사: 448개 참조, 12개 스프라이트 정의, 7개 DDS 이미지 파일 해독 성공. 그림과 마스크 경로 존재 확인. 기본 셰이더 참조는 게임의 `buttonstate.shader`를 사용한다.
- 한국어 파일: `l_korean` 헤더와 UTF-8 BOM 확인.
- 아이콘·한국어 수정 후 실제 게임 표시: 아직 미확인.
- 시험판 효과 중 일부는 실제 기능 대신 설계 효과 안내 문구만 표시한다. 전투·내전·이념 전환·밸런스 등 전체 플레이 검증은 완료하지 않았다.

## 과정에서 개선할 점

정적 검사 통과를 실제 적용 성공과 구분했어야 한다. 처음부터 작은 모드로 로딩과 언어·아이콘을 확인한 뒤 확장하는 편이 적절했다. 중복 파일과 한글 경로를 증거 없이 직접 원인으로 단정한 설명은 잘못이었다. ProcMon 캡처와 사용자 게임 시작 시점도 맞추지 못해 불필요한 재실행 부담이 생겼다. 후속 작업에서는 작게 시험하고, 변경 하나에 결과 하나를 대응시키며, 모드 표시 이름을 고유하게 유지한다.

## 다음 확인

게임을 완전히 재시작한 뒤 현재 고유 이름의 `new_focus` 모드로 니카라과 1936 새 게임을 열어, 첫 중점 `국가 재정비 회의`와 각 중점의 기본 아이콘이 보이는지 확인한다. 기존 `.mod`를 삭제하거나 모드 이름을 예전 중복 이름으로 되돌릴 필요는 없다.
